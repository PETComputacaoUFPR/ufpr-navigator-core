# Classes para o projeto UFPR Navigator

Projeto desenvolvido em TypeScript, utilizando Vite como bundler para desenvolvimento e testes das classes do UFPR Navigator, um projeto do PET Computação.
Partes da estrutura e algumas funções foram baseadas na lógica presente no repositório original ([https://github.com/PETComputacaoUFPR/UFPR_Navigator](https://github.com/PETComputacaoUFPR/UFPR_Navigator)), com adaptações e reimplementação.

Durante o desenvolvimento, devido ao escopo e organização do código, o projeto foi disponibilizado no GitHub.

---

## Pré-requisitos

Certifique-se de ter instalado:

* Node.js (versão 18 ou superior)
* npm (já incluso com o Node.js)
* Git

Para verificar as versões instaladas:

```bash
node -v
npm -v
git --version
```

---

## Clonar o projeto

```bash
git clone <URL_DO_REPOSITORIO>
cd classes-navigator
```

---

## Instalar as dependências

```bash
npm install
```

---

## Executar em ambiente de desenvolvimento

```bash
npm run dev
```
